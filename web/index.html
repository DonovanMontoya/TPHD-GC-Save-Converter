TP Save Tools

Twilight Princess save converter

Copy your stats out of Twilight Princess HD and into a GameCube save, or the other way around. Everything runs locally in your browser.

Convert a save

You need two files: the save you want to convert, and a save of the format you want out.

  1. 1
    The save you want to convert A Twilight Princess HD ZTPxx.dat, or a GameCube .gci. The direction is worked out from the file.
  2. 2
    The save it gets merged into Pick your file above first.
    Don’t have a GameCube save?

    Make one in Dolphin: start a new Twilight Princess file, save at the first owl statue, then Tools → Memory Card Manager, select the save and choose Export. A brand new file works fine — it only needs to be a real save.

Choose both files to continue.

Advanced options

A reference supplies return place, stage memory, and event flags from a coherent checkpoint; your mapped stats and inventory are kept. For the published dungeon pack, the command-line curated-reference workflow remains the most complete option.

Notes

  • Files are processed locally and are not uploaded.
  • You supply your own saves; no Nintendo data is included.
  • TPHD → GC has passed 30/30 automated Dolphin stage-load checks.
  • GC → TPHD is experimental. Keep a backup and test the result in Cemu.
